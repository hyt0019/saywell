# 好好说 Saywell · 使用说明

## 安装和启动

从 [Releases 页面](https://github.com/hyt0019/saywell/releases) 下载最新的 `Saywell-Setup-版本号.exe` 并运行。安装程序装在当前用户目录（`%LOCALAPPDATA%\Programs\Saywell`），不需要管理员权限，会在开始菜单创建“好好说 Saywell”，桌面快捷方式可选。安装新版本时直接运行新的安装包即可覆盖升级，设置、密钥和已下载的模型都会保留。

好好说的英文名早期叫 Better Voice Input。从旧版本升级时，安装程序沿用原来的安装文件夹，并替换旧的程序文件和快捷方式；首次启动新版本时，设置、历史、统计和模型所在的 `%LOCALAPPDATA%\BetterVoiceInput` 会自动改名为 `%LOCALAPPDATA%\Saywell`，保存的 Key 和开机自启项也会自动迁移，不需要重新配置。

如果 Windows 提示“Windows 已保护你的电脑”，这是因为程序尚未购买代码签名证书。点击“更多信息”→“仍要运行”即可；不要通过关闭系统防护解决。

**日常使用：点击目标输入框 → 按住 `Alt+X` 说话 → 说完松开 → 等待识别和整理，文字自动输入。** 不需要打开主窗口，也不需要再次确认。录音和处理时仅显示一个不抢焦点的小状态条。

第一次使用：

1. 打开“设置”，填写 API 地址、该服务的 API Key 和模型名称，保存后生效。密钥进入 Windows 凭据管理器。
2. 点击“下载语音模型”，约 240 MB；下载文件会校验完整性。
3. 选择麦克风。Windows 设置 → 隐私和安全性 → 麦克风，需要允许桌面应用访问。
4. 点击普通文本输入框，按住 `Alt+X` 说话，说完松开。等待整理完成后自动输入。

关闭主窗口会缩小到托盘，右键托盘图标选择“退出”才会结束程序。

设置 → 启动方式中可勾选“开机自启动，登录 Windows 后在托盘运行”，点击“保存设置”后生效。默认关闭；取消勾选并保存即可关闭。该选项仅影响当前 Windows 用户。

## API 配置

支持兼容 Chat Completions 的 API，不限定服务商或模型。填写服务商提供的三个值，然后点“测试连接”：程序会发送一个很短的请求，显示是否连通和响应时间（使用 DeepSeek 时还显示余额）；失败时会说明是密钥、地址、模型名称还是网络的问题。

- **API 地址**：Base URL，例如 `https://api.example.com/v1`，也可填写完整的 `/chat/completions` 地址。请求会自动补全路径，不会重复添加。
- **API Key**：当前地址对应的密钥，按地址分别保存。更换地址时输入框会清空，原服务的密钥仍保留；已有该地址的密钥时可以留空。
- **模型名称**：服务商提供的模型 ID。**请求超时**可调整为 1～120 秒。

原有 DeepSeek 地址、模型和已保存的密钥继续可用，它们只是初始默认值。兼容请求不会向其他服务发送 DeepSeek 专用参数；接口明确拒绝 JSON 格式或输出长度参数时，会去掉相应可选参数重试。原生 Anthropic Messages、Responses 等不同协议需通过兼容网关接入。

## 录音和输入

- 停顿不会自动结束，可以慢慢想、重复和改口。单次最长 2 分钟，到上限会处理已经录下的内容。
- 默认开启“按住快捷键说话，松开结束”。快捷键录音完成后直接输入结果，设置中可更换双键组合，也可切回按一次开始、再按一次结束。
- 全局快捷键录音时会记住目标输入框。输入时仍需位于该窗口和输入控件，光标闪烁、坐标变化或临时焦点变化不再永久阻止输入；如果已切换到其他输入框，回到所需位置按 `Alt+V` 补输。
- 点击主窗口录音或导入文件，只展示结果。需要输入时点击“输入到其他窗口”，在 3 秒内点击目标输入框；或切到目标后按 `Alt+V`。
- 模糊表达、数字或专有名词疑点仅保留提示，不要求确认或编辑，也不会阻止自动输入。旧版“有疑点时暂停自动输入”选项已移除。
- 按 `Esc` 取消正在进行的任务。若 API 超时、返回不完整或整理失败，直接输入完整的识别原文。取消后不会输入任何结果。
- 所有复制和输入统一为单行，换行、制表符转换为空格，保留标点。结果很长时界面可能自动折行，但输入内容没有换行符。
- 终端也支持快捷键直接输入。程序只粘贴文字，不会自动按回车执行或发送；需提交时自行按回车。
- 自动粘贴会暂用剪贴板，在未被用户修改时尝试恢复原内容。特殊应用异步读取剪贴板时，必要时使用“复制结果”。
- **结果留在剪贴板**：在设置 → 录音与输入中开启“输入后把结果留在剪贴板”后，自动输入的结果会留在剪贴板，不再恢复原内容；快捷键录音没找到输入框或自动输入失败时，结果也会放进剪贴板。适合游戏等说话时打不开输入框的场合：先按住快捷键说话，再打开聊天框按 `Ctrl+V` 粘贴。默认关闭。
- **语音翻译**：说完后在最后加一句翻译要求，例如“翻译成英文”“把这句话翻成日语”“用韩语说”，输入的就是整理好的译文，这句要求本身不会被输入。只有放在最后、针对刚才所说内容的要求才会触发；话里提到翻译（如“我要把合同翻译成英文发给客户”）照常整理。“文字”页左侧保留原话，状态栏显示“已翻译为英语”。翻译时只保留通用的核对，不再按中文检查否定和不确定表达。不需要时可在设置 → 录音与输入中关闭“语音翻译”。

## 概览和使用统计

主窗口顶部可以在“概览”和“文字”两页之间切换，默认显示概览：

- **今天、连续使用、累计、省下的打字时间**：省下的时间按每分钟打 40 字估算，减去说话用的时间。
- **说话热力图**：过去一年每天一个格子，颜色越深说得越多；鼠标悬停时格子描边，旁边浮出当天的字数和次数，今天的格子带黑色描边。
- **最近一次**：最新的整理结果，可以直接复制、输入到其他窗口，或点“原文对照”打开“文字”页。
- **API 用量**：本月请求次数和 tokens、今天的 tokens、平均每次的 tokens，以及最近 14 天每天的 tokens（悬停柱子查看当天数字）。使用 DeepSeek 时显示账户余额（可点“刷新”），并按官方价格和请求时段估算本月花费，实际以 DeepSeek 账单为准；其他服务只显示次数和 tokens。
- **里程碑**：累计字数（1 千、1 万、10 万、100 万字）和最长连续使用天数（3、7、30、100 天）两条进度线，达成的节点会填满；悬停节点可以看到还差多少。

统计默认开启，只在本机 `stats.json` 中按天记录字数、次数、录音时长、tokens 和估算花费，不记录任何说话内容。设置 → 隐私与启动中可以关闭统计，或点“清空统计”从零开始。

## 原文、词库和历史

“文字”页左侧是原始识别，右侧是整理结果，二者都可在任务结束后编辑。原文修改后点击“整理文字”可重新处理。

**翻译**：点“翻译”，选择英语、简体中文、繁体中文、日语、韩语、法语、德语、西班牙语或俄语，右侧的整理结果（包括你手动改过的内容）会被译成该语言并替换，按 Ctrl+Z 可以撤销。程序会记住上次选的语言。翻译由“设置”中的 AI 服务完成，计入 API 用量。

在词库中每行添加一个常见人名、项目名或英文术语。例如常用人名、DeepSeek、产品名称。词库用于整理阶段辅助拼写，不保证修复所有识别错误，不应让模型猜测未说出的事实。

麦克风录音只在内存中处理，不生成本地录音文件。本地识别完成后立即释放录音缓存，取消或出错时也会清理，不会等 API 返回后才释放。手动导入的音频是你已有的文件，程序不会复制或自动删除原文件。

文字历史默认关闭；开启后使用 Windows 当前用户加密，**最多只保留最近 5 条，最长 7 天**。新增第 6 条时移除最早的一条。程序启动、访问或新增历史时清理超额和过期记录，包括旧版本留下的历史；关闭开关会停止新增。“历史 → 清空全部历史”可立即删除已保存的文字。

## 语音模型

点击主窗口右上角“语音模型”，或录音卡片中的模型标签，可以下载和切换本地识别模型。默认使用 SenseVoice Small，不选择其他模型时保持不变。窗口分为“精选模型”和“模型广场”两页。

“60 秒语音约”一列是识别一分钟录音所需的时间，数字越小，松开快捷键后越快出字。这是在一台台式电脑上的实测值，普通笔记本通常更慢。

**精选模型**：适合日常听写。

| 模型 | 大小 | 60 秒语音约 | 适合 |
|---|---|---|---|
| SenseVoice Small（默认） | 约 240 MB | 0.9 秒 | 中文准确，自带标点；中文里的英文词和人名偶尔听成近音词 |
| X-ASR 中英 | 约 180 MB | 0.8 秒 | 英文和中英混说更准，大小写规范，体积最小 |
| Qwen3-ASR 0.6B | 约 1.1 GB | 4.2 秒 | 中文准确，嘈杂环境、语速快时也较稳，自带标点；一句话约 1 秒出字；支持 GPU 加速；偶尔把“呃”听成“而” |
| Canary 180M Flash | 约 210 MB | 3.6 秒 | 英文最强，自带标点和大小写；只识别英文（及德、法、西班牙语），说中文时请切回 |

**模型广场**：精选模型之外的 9 个开源模型，适合有特殊需要时选用，可按“中文”“方言”“英文与多语言”筛选。它们普遍更大，部分明显更慢。点击卡片上的“模型主页”可以查看模型介绍和许可协议。

| 模型 | 大小 | 60 秒语音约 | 特点 | 注意 |
|---|---|---|---|---|
| FireRedASR2-AED | 约 1.2 GB | 17 秒 | 中文最准 | 很慢；不带标点，英文全为大写 |
| FireRedASR2-CTC | 约 780 MB | 8.3 秒 | 与 AED 版同源，快一倍 | 仍然偏慢；不带标点，英文全为大写 |
| Fun-ASR-Nano | 约 1.0 GB | 7.8 秒 | 中文准确，远场、嘈杂场景表现好 | 偏慢；中英夹杂的句子偶尔出错 |
| Paraformer 中文 | 约 230 MB | 0.7 秒 | 老牌中文模型，又快又准 | 不带标点，英文全为小写；AI 整理时会补上标点 |
| Dolphin Base | 约 100 MB | 0.6 秒 | 方言最全，体积最小 | 不擅长英文 |
| TeleSpeech | 约 340 MB | 1.3 秒 | 适合方言口音较重的普通话 | 不识别英文、不带标点 |
| Parakeet TDT 0.6B v3 | 约 670 MB | 2.0 秒 | 英语和 24 种欧洲语言 | 不识别中文 |
| Cohere Transcribe | 约 2.9 GB | 6.7 秒 | 英文榜单第一 | 只识别英文；体积最大 |
| Whisper Turbo | 约 1.0 GB | 14 秒 | 99 种语言，自动判断语种 | 很慢；中文常漏字、不带标点 |

- 已下载的模型卡片上有两个检查按钮：“检查文件”逐个校验文件是否完整，发现损坏时点“修复”只重新下载坏掉的文件；“试一试”最长录 10 秒（说完可以点“说完了”提前结束），用这个模型当场识别并显示文字和用时，可以同时检查麦克风。
- 点击“下载”开始下载。下载在后台进行，可以关闭窗口继续使用当前模型；完成后点击“使用此模型”才会切换。
- 窗口顶部可以更改下载位置并查看剩余空间。更改后新下载保存到新位置，已下载的模型留在原处，不需要重新下载。
- 未使用的模型可以删除以释放空间；删除只移除该模型自己的文件。默认的 SenseVoice 不提供删除。
- 切换后第一次识别需要几秒加载模型。所有模型都在本机识别，录音不会上传。
- Qwen3-ASR 由 llama.cpp 引擎运行：下载时会一起下载 CPU 版（约 20 MB）和 GPU 版（约 32 MB）引擎，选用后程序在后台启动一个只供本机使用的识别进程，模型常驻内存，退出程序时一起关闭。0.2.0 中已下载过 Qwen3-ASR 的，升级后需要在“语音模型”里对它再点一次下载，只会补下 GPU 版引擎这一个文件。
- **GPU 加速**：在设置 → 录音与输入中开启后，Qwen3-ASR 用显卡识别，速度更快；卡片上的“支持 GPU 加速”标签标出了可以加速的模型，主界面的模型标签会显示“GPU 加速”。使用 Vulkan，NVIDIA、AMD、Intel 显卡都能用，不需要安装 CUDA；同时有核显和独显时用独显。显卡驱动不支持、显存不足或没有可用显卡时，自动改用 CPU 并提示一次。其他模型在 CPU 上已经足够快，不受这个开关影响。

## 数据位置

- 设置：`%LOCALAPPDATA%/Saywell/settings.json`，不包含密钥。
- 可选加密历史：同目录 `history.json`。
- 使用统计：同目录 `stats.json`，只有按天汇总的数字。Qwen3-ASR 引擎的运行日志在同目录 `llama-server.log`，每次启动时覆盖。
- 模型：默认下载到 `%LOCALAPPDATA%/Saywell/models`，可在“语音模型”中更改。SenseVoice 位于该文件夹根目录，其他模型各占一个子文件夹（例如 `x-asr-zh-en`、`canary-180m-flash`）。更改下载位置后，已下载模型的位置会记录在设置中，不需要重新下载。从源码或便携文件夹运行时，程序旁或项目根目录已有的 `models` 文件夹优先。
- Key：Windows 凭据管理器，服务名 `saywell`（旧版本保存在 `better-voice-input` 下的 Key 会在首次读取时移过来），不同 API 地址使用独立凭据。开发测试可同时设置 `SAYWELL_API_KEY` 和匹配的 `SAYWELL_API_BASE_URL`；旧 `DEEPSEEK_API_KEY` 和根目录 `deepseek api key.txt` 只会用于 DeepSeek 官方接口。
- 音频在本机识别。转写和相关词库发送至所选 API，服务可用性和计费由所选服务商决定。

## 常见问题

**人名或英文识别错了**：检查原文，添加词库或手动修改后重新整理。尤其“不是，是五千”如果被识别成“不是五千”，应核对数字，程序会提示这种歧义。

**快捷键没反应**：可能已被其他程序占用，在设置中更换。也可以点击开始录音。

**无法插入**：点击目标普通文本框后按 `Alt+V`。管理员程序、自定义控件、远程桌面等可能限制模拟输入，使用复制结果即可。

**游戏里说完没有文字**：很多游戏要先打开聊天框才能输入文字。在设置中开启“输入后把结果留在剪贴板”，说完后打开聊天框按 `Ctrl+V` 粘贴（需要游戏的聊天框支持粘贴）。

**CMD / PowerShell 显示已输入但没有文字**：旧版本模拟的 Insert 键缺少扩展键标记，可能未触发终端粘贴；传统控制台的焦点识别也已修正。请退出旧程序并使用重新打包的版本，按住 `Alt+X` 说话、松开后即可输入单行文字。本机普通权限 CMD 和 Windows PowerShell 已通过真实粘贴验证，程序不会自动按回车。

**下载或 API 连接失败**：检查网络及代理。支持标准 `HTTPS_PROXY` / `HTTP_PROXY` 环境变量；不要把代理凭据或 API Key 写入仓库。程序不会自动上传音频到其他服务。

**模型下载中断**：重新点击下载；已完成且通过校验的文件会复用，未完成文件重新下载。所选位置空间不足时会提示更改下载位置。

**用 Canary 说中文结果乱码**：Canary 只识别英文等欧洲语言，说中文或中英混说时请切回 SenseVoice 或 X-ASR。

**出现 SmartScreen 提示**：程序尚未购买代码签名证书，点击“更多信息”→“仍要运行”；也可以从源码自行构建。不要通过关闭系统防护解决。

**卸载**：在 Windows“设置 → 应用”中卸载“好好说 Saywell”。卸载会关闭正在运行的程序，并移除它的开机自启项。设置、加密历史和模型留在 `%LOCALAPPDATA%/Saywell`，重装后可继续使用；不再需要时可手动删除该文件夹，密钥可在 Windows 凭据管理器中删除 `saywell` 条目。
