好好说有了英文名 **Saywell**。这一版换了新图标和全新界面，新增“概览”统计、更准的 Qwen3-ASR 模型和模型广场，并加入了一键检查。

## 下载

下载下方的 `Saywell-Setup-0.2.0.exe` 并运行。安装在当前用户目录，不需要管理员权限。

- 系统要求：Windows 10 / 11（64 位）、麦克风、网络连接。
- 程序暂未进行代码签名。如果 Windows 提示“Windows 已保护你的电脑”，点击“更多信息”→“仍要运行”。
- 可用 `Saywell-Setup-0.2.0.exe.sha256` 核对下载文件是否完整。

**从 0.1.0 升级**：直接运行新安装包即可。0.1.0 发布时英文名叫 Better Voice Input；升级后设置、API Key、已下载的模型、统计和开机自启都会自动迁移，不需要重新配置。

## 新功能

- **新名字和新图标**：中英文名并列为“好好说 Saywell”，配新的应用图标和托盘图标。
- **全新界面**：程序自绘的一套线性图标；按钮的悬停和按下、页面切换、数字变化都有过渡动画；复制后按钮显示“已复制”，底部弹出提示。
- **概览页**：
  - 今天说了多少字、连续使用天数、累计字数，以及大约省下的打字时间；
  - 一张类似 GitHub 活跃图的说话热力图，鼠标悬停可以看当天的数字；
  - 累计字数和连续使用天数两条里程碑；
  - API 请求次数和 tokens 用量；使用 DeepSeek 时显示估算花费和账户余额。

  统计只记数字，不记你说了什么，可以在设置中关闭或清空。
- **Qwen3-ASR 0.6B**（精选模型）：由 llama.cpp 引擎在本机运行，中文更准，嘈杂环境和语速快时更稳，一句话约 1 秒出字。
- **模型广场**：除精选模型外，还可以从更多开源模型中挑选（FireRedASR2、Fun-ASR-Nano、Paraformer、Dolphin、Whisper Turbo 等），适合方言、更高准确率或其他语言。每个模型都写明了特点、识别速度和模型主页。
- **一键检查**：
  - 设置里可以“测试连接”，直接告诉你 Key、模型名或网络哪里有问题；
  - 模型卡片可以校验文件是否完整、只重新下载损坏的部分，或者“试一试”：录 10 秒，当场用这个模型识别。

## 第一次使用

1. 打开“设置”，填写 AI 服务的 API 地址、API Key 和模型名称，点“测试连接”确认可用。
2. 点击“下载语音模型”（默认模型约 240 MB，只需一次）。
3. 在 Windows 隐私设置中允许桌面应用使用麦克风。

完整说明见 [使用指南](https://github.com/hyt0019/saywell/blob/main/docs/USER_GUIDE.md)。

## 已知限制

- 以管理员身份运行的软件、远程桌面等可能限制自动输入，此时可按 `Alt+V` 补输或复制结果。
- 单次录音最长 2 分钟。
- 整理文字需要联网，并会产生所选 AI 服务的费用；按 DeepSeek 官方价格，日常使用一个月通常不到一块钱。
- Qwen3-ASR 和模型广场里的部分模型体积较大，识别速度取决于电脑配置。
