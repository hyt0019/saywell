这一版加入了 GPU 加速和翻译：Qwen3-ASR 可以用显卡识别；说完加一句“翻译成英文”，输入的就是译文；改好的结果也能一键翻译。

## 下载

下载下方的 `Saywell-Setup-0.3.0.exe` 并运行。安装在当前用户目录，不需要管理员权限。

- 系统要求：Windows 10 / 11（64 位）、麦克风、网络连接。
- 程序暂未进行代码签名。如果 Windows 提示“Windows 已保护你的电脑”，点击“更多信息”→“仍要运行”。
- 可用 `Saywell-Setup-0.3.0.exe.sha256` 核对下载文件是否完整。

**从旧版本升级**：直接运行新安装包，设置、API Key、模型和统计都会保留。0.2.0 中已下载过 Qwen3-ASR 的，需要在“语音模型”里对它再点一次下载，只会补下约 32 MB 的 GPU 版引擎。

## 新功能

- **GPU 加速**：在“设置 → 录音与输入”中开启后，Qwen3-ASR 用显卡识别，速度更快。
  - 支持 NVIDIA、AMD、Intel 显卡，不需要安装 CUDA；同时有核显和独显时会用独显。
  - 显卡驱动不支持或没有可用显卡时，会自动改用 CPU 并提示一次。
  - 默认关闭，其他模型不受影响。在新电脑上第一次用 GPU 识别时，需要几秒准备。
- **说完顺手翻译**：说完在最后加一句“翻译成英文”“把这句话翻成日语”“用韩语说”，输入的就是整理好的译文。
  - 只有放在最后、针对刚才那段话的要求才会触发；话里提到翻译，比如“我要把合同翻译成英文发给客户”，会照常整理。
  - 可以在设置中关闭。
- **翻译按钮**：在“文字”页把整理结果（包括你手动改过的）翻译成英语、简体中文、繁体中文、日语、韩语、法语、德语、西班牙语或俄语。
  - 按 Ctrl+Z 可以撤销；程序会记住上次选的语言。

## 已知限制

- GPU 加速目前只用于 Qwen3-ASR；其他精选模型在 CPU 上已经足够快。
- 翻译由“设置”中的 AI 服务完成，需要联网，并计入 API 用量。
- 以管理员身份运行的软件、远程桌面等可能限制自动输入，此时可按 `Alt+V` 补输或复制结果。
- 单次录音最长 2 分钟。
