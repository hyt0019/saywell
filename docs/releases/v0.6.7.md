## 下载

到官网 [saywell.hyt0019.com](https://saywell.hyt0019.com) 下载，或者下载下方的 `Saywell-Setup-0.6.7.exe` 并运行。安装在当前用户目录，不需要管理员权限。

- 系统要求：Windows 10 / 11（64 位）、麦克风、网络连接。
- 程序暂未进行代码签名。如果 Windows 提示“Windows 已保护你的电脑”，点击“更多信息”→“仍要运行”。
- 可用 `Saywell-Setup-0.6.7.exe.sha256` 核对下载文件是否完整。`update.json` 是程序自动更新用的版本信息，不需要下载。

**从旧版本升级**：0.6.6 点主窗口顶部的“更新”即可；0.6.5 及更早的版本没有一键更新，需要手动运行新安装包一次。设置、API Key、模型、词库和统计都会保留。

## 改进

- **更新走国内服务器**：检查更新和下载安装包都先从腾讯云（广州）获取，不再依赖 GitHub 和加速代理；腾讯云连不上时自动改用 GitHub。版本信息照样核对签名，安装包照样核对摘要。
- **官网上线**：[saywell.hyt0019.com](https://saywell.hyt0019.com) 可以下载安装包、查看使用说明和更新日志。

完整说明见 [使用指南](https://github.com/hyt0019/saywell/blob/main/docs/USER_GUIDE.md)。
