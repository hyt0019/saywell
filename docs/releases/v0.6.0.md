这一版的录音快捷键更顺手了：按住键盘右边的 Ctrl 键就能说话，也可以换成右 Alt、CapsLock，或者自己录一个组合键。

## 下载

下载下方的 `Saywell-Setup-0.6.0.exe` 并运行。安装在当前用户目录，不需要管理员权限。

- 系统要求：Windows 10 / 11（64 位）、麦克风、网络连接。
- 程序暂未进行代码签名。如果 Windows 提示“Windows 已保护你的电脑”，点击“更多信息”→“仍要运行”。
- 可用 `Saywell-Setup-0.6.0.exe.sha256` 核对下载文件是否完整。

**从旧版本升级**：直接运行新安装包，设置、API Key、模型和统计都会保留。**原来的快捷键（如 Alt+X）不会被改掉**；想用新的“按住右 Ctrl”，在“设置 → 录音与输入 → 录音快捷键”里选“右 Ctrl”。

## 新功能

- **按住右 Ctrl 说话**（新安装的默认快捷键）：按住键盘右边的 Ctrl 键约 0.3 秒，屏幕下方出现“正在听”后开始说话，松开就整理并输入。
  - 轻按右 Ctrl，或用它和其他键组合（如右 Ctrl+C），仍是原来的功能，不会录音。
- **也可以单独按住右 Alt 或 CapsLock**，用法相同。
  - 按住 CapsLock 说话不会切换大小写，轻按仍然切换。
  - 按住右 Alt 说完松开，不会打开当前程序的菜单栏、抢走输入框的焦点。
- **自定义快捷键**：在录音快捷键列表里选“自定义…”，直接按下想用的组合键（如 Ctrl+Alt+K、Win+Shift+H），或 F1–F24 这类不打字的单键。
  - 单独的字母、数字、空格、方向键会影响打字，不能用。复制、粘贴等常用快捷键，以及补输用的 Alt+V，也不能用。
  - 列表里还保留了 Alt+X、Alt+C、Alt+Q、Alt+Z、Ctrl+Space，新增了 F8。
- 设置窗口打开期间，录音快捷键会暂停，录新快捷键时不会误触发录音。

## 已知限制

- 以管理员身份运行的程序、部分带反作弊的游戏里，单独按住的键可能收不到，可以改用组合键。
- 笔记本的 Fn 键由键盘硬件处理，Windows 收不到，不能用作快捷键。
- 单独按住的键需要约 0.3 秒才开始录音，看到“正在听”再说话，开头的字就不会丢。
