这一版修复了 0.3.0 的联网故障，并新增“输入后把结果留在剪贴板”选项。0.3.0 的打包环境有误，安装后所有需要联网的功能都会失败，常见提示是“[Errno 2] No such file or directory”。正在用 0.3.0 的，请直接安装这一版。

## 下载

下载下方的 `Saywell-Setup-0.4.0.exe` 并运行。安装在当前用户目录，不需要管理员权限。

- 系统要求：Windows 10 / 11（64 位）、麦克风、网络连接。
- 程序暂未进行代码签名。如果 Windows 提示“Windows 已保护你的电脑”，点击“更多信息”→“仍要运行”。
- 可用 `Saywell-Setup-0.4.0.exe.sha256` 核对下载文件是否完整。

**从旧版本升级**：直接运行新安装包，设置、API Key、模型和统计都会保留。

## 修复

- 0.3.0 中失败的这些功能已恢复：
  - 整理文字、说完顺手翻译和翻译按钮（提示“[Errno 2] No such file or directory”）
  - 下载语音模型（提示“模型下载失败，请检查网络或代理后重试”）
  - Qwen3-ASR 识别
  - 查询 API 余额
- 打包时会自动检查程序能否联网，避免同类问题再次发布。

## 新功能

- **结果留在剪贴板**：在“设置 → 录音与输入”中开启“输入后把结果留在剪贴板”。
  - 自动输入后，结果会留在剪贴板，不再恢复成原来的内容。
  - 用快捷键录音时，如果没找到输入框或自动输入失败，结果也会放进剪贴板。
  - 适合游戏等说话时打不开输入框的场合：先按住快捷键说话，再打开聊天框按 Ctrl+V 粘贴（需要聊天框支持粘贴）。
  - 默认关闭。

GPU 加速、说完顺手翻译和翻译按钮的介绍见 [0.3.0 发布说明](https://github.com/hyt0019/saywell/releases/tag/v0.3.0)。

完整说明见 [使用指南](https://github.com/hyt0019/saywell/blob/main/docs/USER_GUIDE.md)。
